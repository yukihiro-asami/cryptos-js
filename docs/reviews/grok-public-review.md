### 公開前に修正すべき問題
なし。

- `sc25519MulAdd`：`x = a·b + c`（非負・各因子 < 2^256 なので x < 2^512）に対し μ = ⌊2^520 / ℓ⌋ を使った近似商 q = ⌊x·μ / 2^520⌋ の後、`s = x − q·ℓ` が ℓ 以上なら1回引く。これは Barrett 還元の標準的な誤差（このパラメータでは高々1）の補正であり、結果は常に [0, ℓ) に入る。定数は `⌊2^520 / L⌋` と一致することを独立に確認した。ゼロseed + メッセージ `0c230000` で不正な s が出ていた現象はこれで解消する。呼び出し側（`signDetached` の最終 s）との整合も問題ない。
- `ge25519P2ToP3`：P2 (X:Y:Z)（x=X/Z, y=Y/Z）から (XZ, YZ, Z², XY) へ写す。アフィン座標は不変で、拡張座標の不変式 X'Y' = Z'T' も成り立つ。T を先に、Z を最後に計算する順序は同一オブジェクト上書きにも安全。独立アフィン計算による位数1・2・4・8の差の回帰試験と整合する。

既存試験2件の修正（再還元で不具合を隠さない、誤った固定期待値を実点＋不変条件へ置き換え）も正しい。
