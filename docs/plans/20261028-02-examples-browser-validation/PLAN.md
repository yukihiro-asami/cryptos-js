## 利用例で扱う内容

| 方式 | 実行して確かめられること |
|---|---|
| Ed25519 | seedからの鍵生成、メッセージの署名と検証、メッセージ改変時の拒否 |
| X25519 | 両者の公開鍵と共有秘密の計算、双方の共有秘密が一致すること |
| SHA-512 | メッセージからハッシュを求め、既知の期待値と一致すること |
| HKDF-SHA-512 | Extract・Expandによる鍵導出。入力と出力長が分かる呼び出し例 |
| ChaCha20-Poly1305 | 鍵・nonce・AADを用いた暗号化と復号、タグ改変時の拒否 |

X25519 → HKDF → ChaCha20-Poly1305のつながりも示す。各方式の呼び出しが追える短さを優先し、汎用のデモ基盤には広げない。既存のAPIを使い、必要なバイト列・BigInt変換は利用例側に置く。

ブラウザでは同じライブラリをES modulesとして直接読み込む。ビルドや外部暗号パッケージを導入せず、5方式の計算をWebCryptoへ置き換えない。入力は公開のテスト値またはその場で生成するデモ値とし、実際の利用者情報や永続的な秘密鍵は使わない。乱数が必要な箇所には実行環境の乱数生成機能を用いる。

## 実施結果（2026-10-28）

5方式の個別例と、X25519 → HKDF-SHA-512 → ChaCha20-Poly1305の組み合わせ例を作成した。Node.jsとブラウザは同じES modulesを読み、計算には既存の参照実装を使う。ブラウザは一括・個別実行、確認項目、入出力の展開、呼び出しコードへのリンクを備える。ライブラリのAPI・計算処理は変更していない。

- Node.js：`npm run examples`。個別には `npm run examples -- ed25519` 等を実行する。
- ブラウザ：`npm run examples:browser` → `http://127.0.0.1:3210/`。別ポートの指定も可能。
- 固定例は公開テスト値。Ed25519はRFC 8032 §7.1 TEST 2、X25519はRFC 7748 §6.1、ChaCha20-Poly1305はRFC 8439 §2.8.2を本文と照合した。[値と出典](../../../examples/vectors.js)を利用例に残した。
- SHA-512のabcとHKDFの期待値は、Node.js標準暗号とPythonのhashlib/hmacで独立に照合した。HKDFはRFC 5869 A.1の入力をSHA-512に適用した値であり、RFC掲載のSHA-256の期待値とは区別した。
- 組み合わせ例は実行ごとにデモ用の鍵・salt・nonceを生成する。認証付き鍵交換プロトコルの実装には広げていない。
- 日英READMEに利用例、起動方法、確認環境を追加し、日英アルゴリズム解説の末尾を実行例への案内に更新した。
